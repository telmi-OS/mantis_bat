# AWS Lambda source bundle

`lambda_function.py` and `test_lambda_function.py` are the supplied AWS client source and offline test file. The deployment ZIP in `public/downloads/` contains only `lambda_function.py` at its root and matches this source copy.

For deployment, environment variables, IAM, deletion behavior, scheduling, limits and troubleshooting, see [the full AWS guide](../../public/downloads/aws-lambda-guide.md). The downloadable IAM example is mirrored in this directory for source review.
