# Changelog

## 0.1.0

- Add standalone Hades installer, protected mail client, IMAP synchronization, and Ghost API v2 presets.
- Add SQLite storage for messages, addresses, server folders, attachments, handling rules, processing state, and a 50-email rolling diary.
- Add Ghost Deleted server folder with app-only restore and permanent deletion.
- Add realtime summaries and notifications plus queued Ghost mail tasks.
- Add rule-aware outgoing mail, one-email authorization, IMAP Sent copy, and explicit attachment upload to Ghost Files with a 2 MB cap.
