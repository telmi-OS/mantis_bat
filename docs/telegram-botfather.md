# Telegram BotFather

Mantis Bat uses a user-owned Telegram bot.

## Basic Flow

1. Open Telegram
2. Search for `@BotFather`
3. Send `/newbot`
4. Choose a bot name
5. Choose a username ending in `bot`
6. Copy the bot token

## What You Need For Mantis Bat

- bot token
- bot username for pairing deep links
- HTTPS webhook target for your deployment

Official reference:

https://core.telegram.org/bots/features#botfather
