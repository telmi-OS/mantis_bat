Verified implementation notes at scaffold time:

- Base URL: https://dev.telmi-ai.com/api/ghost/v2
- Auth: Authorization: Bearer <ghost-jwt>
- Chat: POST /chat
- Inbox: GET /inbox
- Inbox ack: POST /inbox/ack
- Memory upsert: POST /memory/upsert
- Memory list: GET /memory/list
- Memory delete: POST /memory/delete
- Memory search: POST /memory/search
- Settings: GET /settings, POST /settings
